# Work PRD Skill Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `$work-prd` with the LUKUKU standard template, evidence rules, versioned output, and PDF rendering in Codex and Claude Code.

**Architecture:** The skill resolves a bounded scope and builds a sourced claim ledger before filling a bundled HTML/CSS template. A small Python renderer validates the required structure and prints the completed HTML to PDF through Chrome or Chromium. Existing history MCP tools store document versions and provenance; `$dev-plan` remains responsible for development planning.

**Tech Stack:** Markdown skills, HTML/CSS, Python standard library, Chrome/Chromium headless PDF, pytest.

**Spec:** `docs/superpowers/specs/2026-09-20-work-prd-design.md`

## Global Constraints

- Preserve the eight-section LUKUKU PRD structure.
- Do not infer scope, approval, estimates, or developer TODOs.
- Do not bundle the original source PDF in the public plugin.
- Keep source and packaged skill trees byte-identical.
